Manco Labs is a small web development studio based in Louisiana.

## Core capabilities
- Website design, development, and redesign, including WordPress theme work and site migrations
- Web applications built on modern stacks (TypeScript, Python, serverless hosting, hosted databases)
- Ongoing website and software maintenance, updates, and support
- Accessibility work: building to WCAG guidelines and Section 508 expectations, and fixing accessibility issues on existing sites
- Small internal tools: forms, document generation, data lookups, and dashboards

## Recent work
- Rebuilt a nonprofit's WordPress site, including donation and content workflows
- Built a replacement WordPress theme for an existing organization site, staged with review gates
- Built and launched a document-generation web app for a client, hosted on Vercel with a Supabase database
- Rebuilt a client's containerized ticket-lookup tool as a serverless web app with a background job queue

## Not a fit
- Hardware, equipment, or licensed-software resale
- Large-scale systems integration that needs a big team or security clearances
- Work that must be performed outside the United States
